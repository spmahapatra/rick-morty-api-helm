# OpenSpec Explore Command

Activate explore mode to investigate the project structure, existing capabilities, and codebase patterns.

## What This Does

1. Load Project Context: Check openspec/config.yaml for project background
2. List Existing Artifacts: Run openspec list --specs to see what's formalized
3. Understand Current State: Read key project files to understand architecture
4. Identify Patterns: Look for existing design patterns and conventions
5. Surface Gaps: Identify areas needing formalization or improvement
6. Ask Clarifying Questions: Explore interdependencies before proposing changes

## How to Use

Simply type /opsx-explore followed by your topic:

/opsx-explore
/opsx-explore add authentication system
/opsx-explore optimize database queries

## Expected Outcomes

- Deep understanding of the project structure
- Identification of relevant existing specs and capabilities
- Risk and gap analysis
- Recommendations for next steps
- Clarified scope for potential changes

Follow the conversation naturally—think deeply and ask questions as they emerge.
