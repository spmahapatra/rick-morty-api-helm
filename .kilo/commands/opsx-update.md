# OpenSpec Update Command

Modify an existing OpenSpec change when requirements or approach changes during implementation.

## What This Does

1. Load the existing change artifacts
2. Identify what needs updating
3. Review proposal, specs, or design changes needed
4. Update affected artifacts
5. Re-validate tasks against changes
6. Report impact on implementation

## How to Use

Type /opsx-update with the change name:

/opsx-update
/opsx-update rick-morty-api-initial-spec
/opsx-update add-authentication

Describe what changed or what needs updating. The workflow will guide you through modifications.

## Expected Outcomes

- Change artifacts updated to reflect new requirements
- Impact analysis on tasks
- Re-validated implementation plan
- Decisions documented
- Ready to continue implementation

Use this when implementation uncovers new requirements or changes in approach.
