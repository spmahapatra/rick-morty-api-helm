## Development Notes

Development notes from the project are organized in `docs/dev-notes/` with the following categories:
- `debugging/` - Debugging logs and analysis
- `analysis/` - Technical analysis and research
- `cache-docs/` - Cache-specific documentation
- `logging-docs/` - Logging investigation notes
- `process-docs/` - Process documentation

**Note**: Development notes are excluded from Git version control and are for reference during active development.
