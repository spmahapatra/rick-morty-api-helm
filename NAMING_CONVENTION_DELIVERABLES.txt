🎯 NAMING CONVENTION SUMMARY
═══════════════════════════════════════════════════════════════════════════════

PATTERN:
  [CATEGORY]-[PURPOSE]-[TRIGGER]-[FREQUENCY].yml

EXAMPLE:
  ci-test-push-per-commit.yml
   │   │     │    │
   │   │     │    └─ Frequency: per-commit
   │   │     └─────── Trigger: push
   │   └──────────── Purpose: test
   └─────────────── Category: ci

CATEGORIES (6):
  • ci          → Continuous Integration (tests, linting)
  • cd          → Continuous Deployment (builds, deployments)
  • security    → Security & Compliance (scanning, audits)
  • analysis    → Code Analysis (metrics, benchmarks)
  • maintenance → Operations (cleanup, updates)
  • setup       → Configuration (environment setup)

TRIGGERS (6):
  • push      → Every git push
  • pr        → Pull request events
  • tag       → Git tag push
  • manual    → User clicks button
  • scheduled → Cron schedule
  • multi     → Multiple triggers

FREQUENCIES (7):
  • per-commit    → Every git push
  • per-pr        → Each PR update
  • hourly        → Every hour
  • nightly       → Once per night
  • weekly        → Once per week
  • monthly       → Once per month
  • on-demand     → Manual only
